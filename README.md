# AxolotlLauncher

A modern, fast, and independent Minecraft launcher built with **Tauri** and **Angular**. 

The project is fully optimized for **offline mode** — managing builds, profiles, and worlds is done locally and does not require a constant internet connection.

## 🛠 Tech Stack
*   **Frontend:** Angular, TypeScript, HTML/CSS
*   **Backend / Desktop Shell:** Rust (Tauri)

## 🗺 Roadmap

The development process is divided into 3 key stages, smoothly transitioning the project from an MVP into a full-fledged gaming platform:

### 🟩 Stage 1: Alpha (Current Status — Core MVP)
*   [x] Build management architecture: creation, editing, importing, and exporting.
*   [ ] Seamless data migration system from other popular launchers.
*   [x] Support for multiple player profiles.
*   [ ] Direct game launching functionality.
*   [ ] Local resource manager: view worlds, added servers, and player screenshots.

### 🟨 Stage 2: Beta (Content & Personalization)
*   [ ] Built-in store: integration with Modrinth (and potentially CurseForge) for easy mod discovery.
*   [ ] Smart recommendation system for mods and add-ons.
*   [ ] Advanced character customization: a dedicated tab for skin management, 3D model customization, and adding items.

### 🟦 Stage 3: Release v1.0 (Ecosystem & Custom Projects)
*   [ ] Full system tray integration (convenient quick access and background operation).
*   [ ] Built-in editors: tools for basic world editing and an integrated skin editor.
*   [ ] Modular plugin system to extend the launcher's core capabilities.
*   [ ] Project customization mode: a toolkit enabling third-party servers to brand and tailor the launcher for their own needs.
